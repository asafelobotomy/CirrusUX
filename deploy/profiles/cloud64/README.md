# cloud64 profile

The owner's own setup: cloud64 (a media server that sleeps) and cloud-box
(the always-on gateway), with the wake wrapper that reads the router
password from a root-only file. Install notes are in `INSTALL.md`.

This folder is private. It moves out of the repository before the repo is
made public (ROADMAP Phase 7). Secrets and logins are placeholders even
here; the real values live only on the machines.
