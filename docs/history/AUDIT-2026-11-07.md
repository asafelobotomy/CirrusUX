# CirrusUX audit — 7 November 2026

Scope: the whole repository at `69881b5` (v0.6.1 plus Git hosting under `[Unreleased]`). It covers six areas: the gateway and Git hosting, the root helper and agent, the web UI, deploy/host/CI, docs and planning, and the app catalogue.

Method: each area was read by a separate reviewer. Every finding marked **✔** was then checked again against the code. Unmarked findings are code-read but were not re-checked a second time.

Baseline: `make test` passes: file length, gofmt, `go vet`, `go test`, svelte-check (0 errors, 0 warnings, 259 files) and 14/14 UI tests. `go test -race` passes for the gateway, githost, helper, agent, appjob, storage, osupdate and idle packages. shellcheck is clean except for one file that is not part of the checks.

The tests found no critical or exploitable-from-outside defects. The repo is in good health. The real work falls into four groups:

1. **Publication blockers.** Private host names are still in the docs and profile, and the official signing key is missing.
2. **A handful of medium bugs** that break real setups. The worst: app installs always fail when `APPS_BIND` is set.
3. **Hardening at the privilege and network edges.** This covers the dockerfilter, sudoers, the systemd units and the `/git/` endpoint.
4. **Duplicated helpers and stale planning docs.**

Severity: **H** high · **M** medium · **L** low. Effort: **S** < 1 h · **M** half a day · **L** days.

## 9. Checked and fine

- All state-changing calls send `X-Cirrus-Request`, and Origin is checked.
- There is no `{@html}`/`innerHTML`.

- CI actions are pinned by SHA, and CI runs `make test`, `-race` and `make test-host`.
- Every Go environment variable is documented.
- No real IPs, MACs or emails were found; the only account name is the public repo URL.
